# Setup

## 1. Install backend dependencies

```bash
pip install -r requirements.txt
```

This includes FastAPI/SQLAlchemy/Pydantic (API), XGBoost/scikit-learn/SHAP
(models), PyJWT (auth), httpx (load testing), and torch (LSTM benchmark —
this is the heaviest install; skip it if you don't need to run
`ml/train_lstm.py`). Twilio is commented out in `requirements.txt` since
it's optional — the SMS alert flow works without it via a built-in stub.

## 2. Generate the synthetic dataset (if not already present)

```bash
python data_simulator/simulate.py
```

Writes `data/train_events.csv` — trains, routes, stations, and simulated
per-station delay events. `data/train_delay_data.csv` (the real historical
dataset) is a separate file, already included, not generated by this
script.

## 3. Train the models

```bash
python ml/train_model.py               # live ETA residual + quantile models, and the anomaly model
python ml/train_historical_model.py    # historical CSV model (separate pipeline)
python ml/train_lstm.py                # optional: LSTM benchmark, requires torch
```

Each prints its own real evaluation numbers on completion — MAE,
improvement over baseline, quantile coverage, etc. Trust the numbers your
own run prints, not any numbers quoted elsewhere, since results can shift
slightly run to run (train/test split randomness) even with a fixed
`random_state`.

## 4. Run the backend

```bash
uvicorn backend.main:app --reload
```

Starts on `http://localhost:8000`. On startup it seeds the three demo
RBAC accounts (`backend/seed.py`) and warms the feature-table and anomaly
caches (`backend/main.py`) so the first real request isn't slow.

Interactive API docs: `http://localhost:8000/docs` — click "Authorize" and
log in with one of the demo accounts to try protected endpoints directly
from the browser.

Demo accounts: `admin`/`admin123`, `operator`/`operator123`,
`viewer`/`viewer123`. See `docs/API.md` for which endpoints need which
role.

## 5. Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Opens on `http://localhost:5173`. Two views, toggled from the top bar:

- **Live Operations** — pulls real trains/routes from `GET /trains`, live
  predictions from `GET /eta/journey`, and lets you fire
  `POST /simulate/delay-event` to watch the ETA recalculate live.
- **Historical Dataset Test** — a separate panel for testing the
  historical-CSV model on its own, independent of the live simulation.

By default it calls the API at `http://localhost:8000`. If your backend
runs elsewhere, create `frontend/.env`:

```
VITE_API_BASE=http://your-backend-host:port
```

## 6. Load test (optional)

With the backend already running (step 4):

```bash
python scripts/load_test.py --endpoint /trains --concurrency 20 --total-requests 500
```

For `/eta/predict`, grab a real `train_no`/station pair from `GET /trains`
first and pass it in the `--endpoint` query string — see the script's
docstring for the exact invocation. Prints p50/p95/p99 latency and
achieved throughput from your own run.

## 7. SMS alerts — optional real Twilio path

By default, alerts use a stub that logs what would have been sent (see
`backend/sms_provider.py`) — no setup needed to demo the full
subscribe→delay→notify flow. To send real SMS via Twilio instead, set:

```bash
export TWILIO_ACCOUNT_SID=...
export TWILIO_AUTH_TOKEN=...
export TWILIO_FROM_NUMBER=...
```

before starting the backend, and uncomment `twilio==9.3.2` in
`requirements.txt`.

## Troubleshooting

- **`ModuleNotFoundError`** for `fastapi`/`xgboost`/`shap`/`torch`/`jwt` —
  `pip install -r requirements.txt` didn't complete; check for errors
  above the failure, especially around `torch` (large download) or
  `xgboost` (needs a prebuilt wheel for your Python version).
- **`503` on `/historical/predict` or `/historical/meta`** — the
  historical model hasn't been trained yet; run
  `python ml/train_historical_model.py` (step 3).
- **`401 Not authenticated` / `403 Requires role...`** — you're hitting a
  protected endpoint without a token, or with a role that's too low. Get
  a token from `POST /auth/token` first and check `docs/API.md` for the
  required role.
- **Frontend can't reach backend** — confirm `uvicorn backend.main:app`
  is running and `VITE_API_BASE` (if set) points at it.
- **`/eta/predict` or `/eta/journey` returns 404** — the train number or
  station code isn't in the currently generated dataset; check
  `GET /trains` for valid values (randomly generated by `simulate.py`).
- **`ml/train_lstm.py` or `scripts/load_test.py` fails or is slow** —
  these are the two components not pre-run in this build; run them
  yourself and read their own docstrings/output for what's expected.
