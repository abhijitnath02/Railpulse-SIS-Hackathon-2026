# RailPulse React Dashboard

A Vite + React recreation of the supplied RailPulse dashboard screenshot.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Structure

- `src/main.jsx` — React components and dashboard data
- `src/styles.css` — layout, colors, gradients, cards, map and table styling
- `index.html` — Vite entry point
